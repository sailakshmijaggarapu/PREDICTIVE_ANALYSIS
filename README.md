# Predictive Analytics Using Historical Data

This project uses the AirPassengers dataset to predict future passenger trends using Linear Regression.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## What I Did
- Loaded and cleaned historical passenger data
- Created features like lag values and rolling averages
- Trained a Linear Regression model
- Predicted future passenger counts
- Evaluated model accuracy using RMSE, MAE, and R²
- Visualized results using graphs

## Output Graphs
- Historical Passenger Trend
- Actual vs Predicted Values
- Residual Error Plot

## Files
- `Passengers.py`
- `AirPassengers.csv`
- `plot1_historical.png`
- `plot2_predictions.png`
- `plot3_residuals.png`
  
## How to Run

```bash
pip install pandas numpy matplotlib seaborn scikit-learn
python Passengers.py
```
